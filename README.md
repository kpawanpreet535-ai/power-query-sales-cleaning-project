# Power Query Sales Cleaning & Analysis

## Project Overview

This project focuses on cleaning, transforming, and analyzing sales data using **Microsoft Excel Power Query**.

The dataset contains sales records from three months. The data was combined and cleaned using Power Query, followed by basic analysis to answer business questions.

## Tools Used

- Microsoft Excel
- Power Query

## Data Preparation & Transformation

The following Power Query techniques were used:

- Appended data from three monthly sheets
- Removed blank rows
- Removed duplicate records
- Changed data types
- Trimmed extra spaces
- Replaced null values
- Created a calculated Net Amount column
- Standardized category names
- Reordered and renamed columns

## Business Questions

1. Which product was sold the most?
2. Which city had the most orders?
3. Which payment mode was used most frequently?

## Key Findings

- **Most sold product:** Pen — 30 orders
- **City with most orders:** Ludhiana — 15 orders
- **Most used payment mode:** UPI — 19 orders

## Project Outcome

This project helped me practice real-world data cleaning and transformation using Power Query and understand how cleaned data can be used to answer basic business questions.
